# Time-Management-Web-Application
# 時間管理アプリ

## 概要

時間管理アプリは、ユーザーが予定やタスクを登録し、効率的に時間を管理することを目的としたアプリケーションです。

## 主な機能

* タスクの追加
* タスクの編集
* タスクの削除
* タスク一覧の表示
* 締切日時の設定
* タスクの完了・未完了の切り替え
* タスクの検索・並び替え（予定）

## 使用技術

* 言語：Python 3.13
* フレームワーク：Django
* データベース：SQLite3
* 開発環境：VSCode, Windows, Git / GitHub


## 画面構成

1. ログイン画面（必要な場合）
2. ホーム画面
3. タスク一覧画面
4. タスク登録画面
5. タスク編集画面

## システムの流れ

1. ユーザーがタスクを登録する。
2. 登録されたタスクをデータベースへ保存する。
3. タスク一覧を表示する。
4. 必要に応じて編集・削除・完了登録を行う。

## データ項目

| 項目    | 内容       |
| ----- | -------- |
| タスク名  | タスクのタイトル |
| 内容    | 詳細説明     |
| 締切日時  | タスクの期限   |
| 優先度   | 高・中・低    |
| ステータス | 未完了・完了   |
| 作成日時  | 登録日時     |
